Security

How this area is protected

Server-enforced login

The gate is configured in admin/.htaccess and checked by Apache/LiteSpeed before any file is sent. There is no password in the page itself, so it cannot be read from the browser.

Credentials off the repo

The password hash lives in a .htpasswd file on the server only. It is listed in .gitignore and is never published to GitHub.

Signing out

Basic authentication has no sign-out button. Close the browser (or the private window) to end the session — some browsers keep the credentials cached until then.

Rotating the password

Run openssl passwd -apr1 'new-password' and replace the line in .htpasswd. No deploy is required.
